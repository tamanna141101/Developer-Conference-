# 🚀 DevConf 2026

A modern and responsive **Developer Conference landing page** built with **HTML5 and CSS3**.

**DevConf 2026** is a conference-themed frontend project featuring developer speakers, conference pricing plans, and a NextGen Hackathon section with multiple challenges.

## 🌐 Project Overview

DevConf 2026 is designed as a clean and modern conference website for developers, engineers, founders, and builders.
🌐 Live Demo

🔗 [View Live Website](https://developer-conference-sable.vercel.app/)
The website focuses on:

* Developer conference information
* Featured speakers
* Conference ticket pricing
* Hackathon challenges
* Registration call-to-actions
* Responsive and visually appealing UI

## ✨ Features

### 🧑‍💻 Hero Section

* DevConf 2026 branding
* Conference introduction
* "Register Now" call-to-action
* Full-width background banner
* Dark overlay for better text readability

### 🎤 Meet the Speakers

* Speaker profile cards
* Speaker images
* Speaker names
* Technology/category badges
* Professional information

### 💳 Conference Pricing

Three pricing plans are included:

* **Standard — $399**
* **Pro — $749**
* **Team — $5,999**

Each plan includes different conference benefits and features.

### 🏆 NextGen Hackathon

The website includes a dedicated hackathon section featuring three challenges:

#### AI for Good

* Track: AI / ML
* Prize: $5,000
* Registration deadline: August 10, 2026

#### Web3 Revolution

* Track: Web Development
* Prize: $4,000
* Registration deadline: August 10, 2026

#### Mobile First Future

* Track: Mobile
* Prize: $3,000
* Registration deadline: August 10, 2026

Each challenge includes:

* Challenge description
* Details button
* Prize information
* Registration deadline
* Join Challenge button

### 🦶 Footer

* DevConf branding
* Social media icons
* Copyright information

## 🎨 Design Highlights

The project follows a modern conference-style visual design with:

* Clean light theme
* Rounded cards
* Consistent spacing
* Bold typography
* Blue primary buttons
* Color-coded hackathon badges
* Card shadows
* Responsive layout structure
* Full-width hero section

## 📱 Responsive Design

The layout is structured using CSS Grid and Flexbox to make the website adaptable to different screen sizes.

The main sections use flexible containers and grid layouts for:

* Speaker cards
* Pricing cards
* Hackathon challenge cards
* Navigation and footer elements

## 🚀 How to Run

No installation or build tools are required.

### Step 1 — Clone the Repository

```bash
git clone https://github.com/tamanna141101/Developer-Conference-.git
```

### Step 2 — Open the Project

Open the project folder in VS Code or any code editor.

### Step 3 — Run the Website

Simply open:

```text
index.html
```

in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.
